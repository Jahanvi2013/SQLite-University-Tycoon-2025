# SQLite-University-Tycoon-2025
This repository holds code that models the gameplay of University Tycoon using a relational database and SQL queries.

The files included are as follows:
create.sql : This file contains the statements required to create the structure of your database, aswell as triggers.
populate.sql : This file contains the statements required to populate your database
view.sql : This file contains the statement that creates the view
q1.sql : Round 1, move 1
q2.sql : Round 1, move 2
q3.sql : Round 1, move 3
q4.sql : Round 1, move 4
q5.sql : Round 2, move 1
q6.sql : Round 2, move 2
q7.sql : Round 2, move 3
q8.sql : Round 2, move 4
